# Enot

Voice and meeting audio → Markdown notes in your Obsidian vault.

Install the plugin, tap the raccoon icon, record or upload a file. Enot processes the audio in the cloud and the plugin writes the note into your vault.

## Install

**Settings → Community plugins → Browse → Enot → Install → Enable.**

Then open Enot settings and press **Register**. Default API: `enot.upl.one`.

## Use

1. Tap the raccoon in the left ribbon.
2. Choose **Microphone** (record) or **Upload file**. While recording, a mini recorder shows the waveform. Tap **Stop & send** when done.
3. Leave Obsidian open (or reopen later) so the finished note can sync.

Works on desktop and mobile Obsidian. An Apple Shortcut is optional if you want to capture outside Obsidian.
